# Cloud Reliability & Deployment Platform

A cloud infrastructure and reliability engineering
portfolio project using AWS, Terraform, Python,
containerization, and GitHub Actions.

## Objectives

- Deploy a tested application to AWS.
- Define cloud infrastructure using Terraform.
- Automate deployments using GitHub Actions.
- Implement monitoring, logging, and alerts.
- Demonstrate rollback and recovery from failures.
